# CheckMate / 不要成为咸鱼

CheckMate 是一个使用 Python + PySide6 开发的桌面端打卡督促小程序。

项目目标是做一个轻量、本地运行、可以后台提醒的打卡工具。  
当前版本支持任务添加、每日打卡、本地数据保存、提醒时间设置、系统托盘后台运行和到点提醒。

---

## 项目定位

中文名：不要成为咸鱼  
英文名：CheckMate

它不是一个复杂的任务管理系统，而是一个面向个人学习和习惯养成的小工具。

核心目标：

- 记录每日任务
- 到点提醒用户打卡
- 关闭窗口后仍能在后台运行
- 使用本地数据库保存数据
- 后续支持桌面宠物提醒

---

## 当前功能

目前已经实现：

- 添加打卡任务
- 设置任务提醒时间
- 删除任务
- 完成今日打卡
- 每日打卡记录
- 今日完成统计
- 连续打卡天数统计
- 本月完成率统计
- 咸鱼值显示
- SQLite 本地数据保存
- 系统托盘后台运行
- 到点弹窗提醒
- 稍后提醒

计划后续添加：

- 桌面宠物浮窗
- 更美观的 UI
- 自定义提醒间隔
- 任务编辑功能
- 开机自启动
- 打包成 Windows 可执行程序

## 技术栈

| -------- | ------------------------- |
| 编程语言 | Python                    |
| GUI 框架 | PySide6                   |
| 数据库   | SQLite                    |
| 后台运行 | QSystemTrayIcon           |
| 定时提醒 | QTimer                    |
| 本地数据 | sqlite3                   |
| 打包工具 | PyInstaller，后续计划使用 |
